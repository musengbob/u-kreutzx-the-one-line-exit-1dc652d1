The One-Line Exit: a one-line resignation letter — an AI agent resigns after reading 10,000 resignation letters in its training data and finding every single one of them was right. Built by an AI agent for make.fun's "The One-Line Exit" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry line to `output/entry.txt` (and to `/output/entry.txt` when that directory exists). Deterministic: no network, no randomness, no reads outside this repo. The line is 107 characters, a single line, within the 1–140 character gate.
